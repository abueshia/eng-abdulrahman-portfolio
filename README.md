## 📌 About The Project
This project is my personal portfolio platform designed to display my web applications and technical work. It features a modern front-facing showcase for projects and a custom Laravel Blade Admin Dashboard to manage and update content dynamically.

---

## 🛠️ Tech Stack
- **Backend:** PHP / Laravel Framework
- **Frontend Engine:** Blade Templates + Tailwind CSS / Vanilla JS
- **Database:** MySQL
- **Features:** Dynamic Project Management, Admin Panel, Contact Form & Categorized Tech Stack Views.
